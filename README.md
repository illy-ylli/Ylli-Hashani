# Ylli’s portfolio

A little 3D world I built for my portfolio. Scroll around the lake to see what I’m studying, the tools I use, and a few placeholder project ideas.

[Explore the portfolio](https://illy-ylli.github.io/Ylli-Hashani/)

Built with React, TypeScript, and Three.js. To run it locally, use `npm ci` and `npm run dev`. The portfolio content lives in `src/config/portfolio.ts`.
